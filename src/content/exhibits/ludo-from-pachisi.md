Ludo is a race game. Players move their tokens around a board and try to reach home before anyone else. It has a long history in India, where it began as **pachisi**, an older game that was first played on cloth boards using cowrie shells.

Over time the Indian version was simplified. It moved to a square board and a single die, and that version is still played in many Indian homes today. The name **Ludo** comes from Latin and means "I play".

In 1896 Alfred Coller marketed the game as Ludo in England, and later patented it. Ludo is for two to four players, and each player has four tokens. The standard game uses one die, although some Indian and Pakistani versions use two.

> **Look closer:** Ludo's name was also borrowed for another famous game. Cluedo's name blends "clue" with "Ludo".
